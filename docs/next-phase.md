# Next phase: 직접 기록하는 여행 지구본

현재 단계는 공개 지구본 탐색을 넘어, 계정을 만들고 자신의 여행을 직접 관리하는
첫 쓰기 버전까지입니다. 이 문서는 이제 실제 출시 전 남은 일을 정리합니다.

## 시작 전 안정화

1. 운영 백엔드의 절전·콜드 스타트 정책을 정리하고 첫 요청 대기 시간을 제거합니다.
2. Render의 `demo` 프로필과 데모 DB를 실제 사용자용 `prod` 환경과 분리합니다.
3. API 오류율, 응답 시간, 프론트엔드 예외를 확인할 기본 모니터링과 DB 백업을 준비합니다.

## 구현 순서

1. **완료: 인증과 소유권** — 회원가입, 로그인·로그아웃, DB 세션, 프로필 수정, 소유자 검사
2. **완료: 여행 CRUD** — 제목·기간·공개 범위, 방문 장소·사진 URL, 수정·삭제
3. **다음: 사진 업로드** — 객체 저장소, 리사이즈와 CDN, EXIF 제안, 원본 메타데이터 제거
4. **다음: 작성 복구** — 자동 임시 저장, 작성 중 이탈 경고, 네트워크 실패 재시도
5. **출시 준비** — 이메일 인증·비밀번호 재설정, 요청 제한, 모니터링, 백업 복구 훈련

팔로우, 피드, 좋아요 같은 소셜 기능은 개인 기록 작성이 안정화된 뒤에 검토합니다.

## 첫 배포의 완료 기준

- 사용자가 로그인해 여행 한 건과 방문 장소를 만들고 다시 수정할 수 있습니다. **완료**
- 업로드한 사진이 모바일과 데스크톱에서 알맞은 크기로 제공됩니다.
- 공개 범위를 바꾸면 API, 검색 노출, 공유 주소에 즉시 같은 정책이 적용됩니다.
- 저장 실패 시 입력 내용이 사라지지 않고, 사용자가 다시 시도할 수 있습니다.
- 새 화면의 문구와 타이포는 [editorial-guide.md](editorial-guide.md)를 따릅니다.

## 현재 베타의 경계

- 이메일은 로그인 식별자로만 사용하며 아직 인증 메일과 비밀번호 재설정은 없습니다.
- 사진은 URL만 저장합니다. 직접 업로드를 붙일 때는 S3/R2 같은 객체 저장소를 사용합니다.
- 국가 선택은 ISO 전체 목록을 제공하지만, 도시 검색·좌표 자동 완성은 아직 수동입니다.
- `demo` DB는 공개 샘플과 테스트 계정이 섞일 수 있습니다. 출시 전에 반드시 별도 `prod` DB로 전환합니다.
