# Next phase: 직접 기록하는 여행 지구본

현재 단계는 공개 지구본 탐색을 넘어 계정, 여행 CRUD, 지도 기반 장소 선택, 사진 업로드,
작성 복구와 계정 복구까지 갖춘 비공개 베타 후보입니다. 이 문서는 다음 개발 경계를 정리합니다.

## 시작 전 안정화

1. Render 운영 서비스를 `prod` 프로필과 전용 DB·메일·R2 환경변수로 연결합니다.
2. Neon 복구 리허설과 GitHub Production smoke를 실제 운영 주소로 한 번 실행합니다.
3. Vercel Firewall의 인증 API 요청 제한을 Log 모드로 관찰한 뒤 차단으로 전환합니다.

## 구현 순서

1. **완료: 인증과 소유권** — 회원가입, 로그인·로그아웃, DB 세션, 프로필 수정, 소유자 검사
2. **완료: 여행 CRUD** — 제목·기간·공개 범위, 방문 장소·사진 URL, 수정·삭제
3. **완료: 사진 업로드** — R2 직접 업로드, 진행률, 대표 사진, 순서·장소 연결, 삭제
4. **완료: 작성 복구** — 자동 임시 저장, 복구·폐기, 작성 중 이탈 경고, 장소 순서 편집
5. **완료: 계정 안전장치** — 이메일 인증, 비밀번호 재설정, 회원 탈퇴, 만료 토큰 자동 정리
6. **완료: 간편 여행 계획** — 나라·날짜·취향 선택, 날짜별 일정, 빠른 슬롯 추가·복사, 준비 체크리스트
7. **완료: 예산·예약과 기록 전환** — 비용·예약 전체 편집, 완료된 계획 발견, 실제 장소 점검과 한 번의 공개 전환
8. **완료: 여행 마무리** — 끝난 계획에서 준비 화면을 걷어내고 실제 장소·대표 장면·짧은 기록만 검토해 공개
9. **현재: 비공개 베타** — 운영 환경 연결, 요청 제한, 복구 리허설, 5~10명 사용성 검증

회원 검색·추천·팔로우, 좋아요·댓글과 최근 활동까지는 구현했습니다. 실시간 알림과
알고리즘 피드는 베타에서 실제 교류 빈도를 확인한 뒤 범위를 결정합니다.

## 첫 배포의 완료 기준

- 사용자가 로그인해 여행 한 건과 방문 장소를 만들고 다시 수정할 수 있습니다. **완료**
- 업로드한 사진이 모바일과 데스크톱에서 알맞은 크기로 제공됩니다. **완료**
- 공개 범위를 바꾸면 API, 검색 노출, 공유 주소에 즉시 같은 정책이 적용됩니다. **완료**
- 저장 실패 시 입력 내용이 사라지지 않고, 사용자가 다시 시도할 수 있습니다. **완료**
- 새 화면의 문구와 타이포는 [editorial-guide.md](editorial-guide.md)를 따릅니다.

## 현재 베타의 경계

- 베타의 핵심 검증 대상은 계획을 일정·사진 기록으로 전환하는 흐름이며, 소셜 기능은 보조 지표로 관찰합니다.
- 지도·지오코딩은 공개 OSM 기반 서비스라 광범위한 공개 출시 전 SLA가 있는 공급자로 전환해야 합니다.
- 사진은 브라우저에서 리사이즈하고 EXIF 촬영일·GPS로 일정 연결을 제안하며, 공개 저장본에서는 JPEG 메타데이터를 제거합니다.
- 설치형 PWA는 개인 API나 비공개 HTML을 캐시하지 않고 정적 앱 셸과 오프라인 안내만 보관합니다. 현장 일정·메모 동기화는 계정별 브라우저 저장소를 사용합니다.
- 운영 플랫폼의 실제 환경변수, Vercel Firewall 규칙, Neon 보존 기간은 코드만으로 켜지지 않습니다.

초대와 피드백 기준은 [`beta-checklist.md`](./beta-checklist.md)를 따릅니다.
