# Editorial guide

Travel Globe의 문장은 여행을 과장하지 않고, 오래된 기록을 차분히 다시 꺼내 보는
느낌을 지향합니다. 새 화면을 만들 때도 아래 기준을 그대로 사용합니다.

## 문장 톤

- 핵심 정보와 행동은 한국어로 씁니다.
- 짧은 영문 라벨은 `TRAVEL JOURNAL`, `CITY ROUTE`처럼 화면의 장르를 알려줄 때만 씁니다.
- “감성적인 경험”, “특별한 순간”처럼 의미가 넓은 표현보다 실제로 할 수 있는 행동을 설명합니다.
- 버튼은 `보기`, `둘러보기`, `돌아가기`, `해제`처럼 결과가 분명한 동사로 끝냅니다.
- 빈 화면과 오류 문구는 원인 한 줄, 다음 행동 한 줄이면 충분합니다.

## 줄바꿈과 정렬

- JSX의 `<br>`와 문자열의 `\n`으로 문장 모양을 고정하지 않습니다.
- 제목은 `text-wrap: balance`, 본문은 `text-wrap: pretty`와 `word-break: keep-all`에 맡깁니다.
- 본문 한 줄 길이는 약 34~56자로 제한하고, 문단 안에서 설명의 시점을 바꾸지 않습니다.
- `오른쪽`, `휠`, `마우스`처럼 특정 화면 크기나 입력 장치에만 맞는 안내는 피합니다.
- 날짜는 `YYYY.MM.DD`, 범위는 `YYYY.MM.DD — YYYY.MM.DD`, 장소 사이는 `·`로 통일합니다.

## 서체 역할

- 큰 제목과 짧은 인용문: Noto Serif KR
- 본문, 버튼, 메뉴, 장소명: Geist + Noto Sans KR
- 날짜, 좌표, 번호, 짧은 영문 데이터: Geist Mono

사용자가 입력한 여행 제목, 메모, 사진 설명은 고치지 않습니다. 서비스가 작성한 안내 문구와
사용자 콘텐츠를 시각적으로 분리하고, 긴 사용자 문장은 안전하게 줄바꿈되도록 처리합니다.
