# 운영 검증 — 2026-10-26 (한국 시간)

대상: https://travel-globe-minani99.vercel.app/ 및 연결된 Render API.
이번 작업은 운영 연결 검증이며 애플리케이션 코드나 배포 설정을 변경하지 않았다.

- `production-account-smoke.spec.ts` 운영 실행 성공(34.7초): 임시 계정 생성 및 세션 확인, 비공개 여행 생성·수정·목록 조회.
- 실제 운영 페이지의 Chromium에서 R2 서명 URL로 사진 업로드 성공. 공개 이미지 조회 및 콘텐츠 타입, 사진 삭제 성공. 해당 브라우저/출처의 업로드 CORS가 작동함을 확인했다.
- 점검 계정 삭제 성공 및 이후 인증 API의 401 응답 확인. 테스트가 만든 사진과 계정을 정리했다. 계정 삭제에 연결된 여행의 제거는 계정 삭제 동작에 의존하며 별도 DB 조회는 하지 않았다.
- 공개 설정 API는 사진 저장소 `configured=true`, 검색 공급자 `maptiler`, 키 존재를 반환했다. 키 값은 보고서에 기록하지 않았다.

## 아직 완료로 표시하지 않은 항목

1. **Google 실제 경로**: 코드와 모의 응답 검사와 별도로 Google Cloud 결제 연결, API 활성화, 키 제한, 실제 경로 응답 확인이 필요하다. MapTiler 설정 확인은 Google 설정 확인을 대신하지 않는다.
2. **메일**: Resend 도메인 인증 및 실제 받은편지함에서 가입 인증·비밀번호 재설정 메일 수신 확인. 이번 점검 계정은 example.com 주소이므로 메일 전달 검증이 아니다.
3. **복구**: Neon 콘솔의 실제 보존 기간과 별도 복구 브랜치에서의 복원 리허설. 운영 DB 복구나 변경은 수행하지 않았다.
4. **플랫폼 설정**: Render prod 프로필·전용 DB, 환경변수의 실제 값, 키의 허용 출처, Vercel Firewall 및 각 플랫폼 장애 알림 수신 여부는 콘솔 증거가 필요하다. 공개 API 정상 응답만으로 완료 처리하지 않았다.
5. **실제 모바일 기기**: iOS·Android 설치, 독립 창 실행, 비행기 모드 및 계정 전환 후 비공개 데이터 분리 확인. 데스크톱 Chromium 검증과 구분한다.
6. **사용성 검증**: 5~10명의 실제 여행 계획·기록 작성 피드백 수집. 초대나 메시지 전송은 수행하지 않았다.

## 실행 범위

운영 계정 검사는 명시적인 `PRODUCTION_ACCOUNT_SMOKE=1`과 운영 `PLAYWRIGHT_BASE_URL`로 실행했다. 재시도는 0회, trace는 비활성화했다. 기존 사용자 계정이나 여행 기록은 사용하지 않았다. 인증 정보와 서명 URL은 이 문서에 포함하지 않는다.
